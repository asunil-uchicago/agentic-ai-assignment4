What RepoMind remembers about this repository, from earlier runs. Each line gives
a record's id, its kind, where it came from, how old it is, and whether anything
confirmed it, before the memory itself.

How to treat each kind of line:

- A record whose source is `user` is a rule a maintainer of this repository
  stated. It is how the team works here, and it holds for this issue too: follow
  it, even when the code or the issue would suggest something else, and do not go
  looking for confirmation of it.
- A record whose source is `memory` is RepoMind's own earlier work. It is a lead,
  not a finding: use it to know where to look, and let what this run sees decide.
- A record whose source is `repo` is read from the repository's own files, and may
  be out of date; the file wins when the two disagree.

A memory never replaces this run's own reading of the issue, and never changes the
two lines the comment must begin with, except where a maintainer's rule says what
one of them is.
